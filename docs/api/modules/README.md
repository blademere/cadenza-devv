# Module Documentation

This directory contains documentation for implemented application/domain modules.

## Rules

- Keep domain-specific workflows, terminology, policies, and business rules here.
- Keep reusable mechanisms in the general `docs/server/` documentation.
- Do not document an unimplemented module as if it were production functionality.
- Each module should have a `README.md` describing its current scope and boundaries.
